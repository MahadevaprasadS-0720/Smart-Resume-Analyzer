## 🔆 Overview

**Smart Resume Analyzer** is a next-generation, high-performance, and feature-rich career optimization web application engineered with a sleek modern UI, buttery-smooth interactions, and bulletproof security. Built to deliver lightning-fast client-side document processing, it offers deterministic ATS scoring metrics, real-time keyword coverage comparisons, automated cloud persistence, and an exceptional workflow tailored for competitive career standards.

---

## 🔥 Key Features

* 🔒 **Enterprise Authentication Matrix:** Seamless Google OAuth sign-in, multi-tab session persistence, and secure token lifecycle managed by Firebase Auth.
* 📄 **Client-Side PDF Extraction Pipeline:** Ultra-fast, zero-latency document parsing directly in the browser via PDF.js, ensuring 100% data privacy.
* 🎯 **Deterministic ATS Scoring Engine:** High-precision evaluation matrix calculating keyword match density against targeted Job Descriptions (JD).
* ⚡ **Dynamic Gap Analysis & Skill Breakdown:** Instant categorization of matched proficiencies, missing core requirements, and actionable profile recommendations.
* ☁️ **Cloud Storage Vault & Resume Archival:** Secure asset management pipeline archiving generated records and uploaded files to Firebase Storage.
* 📊 **Real-Time Scan History & Persistence:** Cloud Firestore-powered historical scan vault enabling instant tracking of previous analyses.
* ✨ **Fluid Micro-Interactions & Animations:** Polished interactive transitions and state animations orchestrated with Framer Motion.
* 📱 **Adaptive Responsive UI/UX:** Precision-crafted layout optimized for flawless visual alignment across mobile phones, tablets, laptops, and ultra-wide desktops.

---

## 🛠 Tech Stack

* **Frontend Framework:** React 18 with Vite
* **Styling & Design System:** Tailwind CSS, Lucide React
* **Motion & Animation Engine:** Framer Motion
* **Text Extraction & Processing:** PDF.js (`pdfjs-dist`)
* **Authentication & Backend Services:** Firebase Auth, Cloud Firestore, Firebase Storage
* **Production Deployment:** Firebase Global Hosting
