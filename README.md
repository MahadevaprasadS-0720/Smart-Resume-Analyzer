# Smart Resume Analyzer 🚀

A modern, high-performance web application designed to help job seekers optimize their resumes for Applicant Tracking Systems (ATS).

## 🌟 Overview
Smart Resume Analyzer is a serverless application built to provide instant feedback on resumes. It parses PDFs on the client side, compares the content against job descriptions, and provides an ATS score, highlighting missing skills and matched keywords.

## 🎯 Key Features
* **ATS Optimization:** Calculates a score based on keyword matching.
* **Client-side Parsing:** Uses `pdfjs-dist` to extract text securely in the browser.
* **Secure Authentication:** Built with Firebase Auth for seamless Google Sign-In.
* **Resume Vault:** Securely stores your resume PDFs in Firebase Storage.
* **Scan History:** Keeps a track of your analysis history in Firestore for easy access.
* **Modern UI:** Clean, minimalist design with smooth Framer Motion animations.

## 🛠 Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Backend/DB:** Firebase (Auth, Cloud Firestore, Hosting, Storage)
* **Animations:** Framer Motion
* **Resume Parsing:** PDF.js
* **Icons:** Lucide React
