## 🌟 Overview

Smart Resume Analyzer is a next-generation career tool designed to optimize resumes for Applicant Tracking Systems (ATS). Engineered for speed and accuracy, it leverages advanced client-side PDF parsing and real-time cloud syncing to deliver instant, actionable feedback, helping job seekers stand out in a competitive market.

---

## ⚡ Key Features

* **Client-Side AI Analysis:** Extract text and analyze keyword coverage directly in the browser without backend delays.
* **ATS Score & Insights:** Get precise matching scores with actionable improvement tips and missing skill identifiers.
* **Secure Authentication:** Seamless Google Sign-In integration powered by Firebase Auth.
* **Instant Cloud Vault:** Automatic, secure storage and retrieval of resumes via Firebase Storage.
* **Interactive Dashboard:** Visualize keyword coverage and skill gaps with a polished, minimalist UI.
* **Smooth Animations:** Fluid, delightful transitions powered by Framer Motion.
* **Real-time History Sync:** Instant data persistence and historical scan tracking in Cloud Firestore.
* **Responsive Layout:** Perfectly optimized for mobile, tablet, and desktop screens.

---

## 🛠 Tech Stack

* **Frontend:** React, Vite, Tailwind CSS, Framer Motion, Lucide Icons.
* **State & Storage:** Firebase (Authentication, Cloud Firestore, Cloud Storage).
* **Resume Processing:** PDF.js (Client-side parsing).
* **Deployment:** Firebase Hosting & GitHub.
