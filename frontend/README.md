# Smart Resume Analyzer - Frontend

A modern React application built with **Vite**, **Tailwind CSS**, **Lucide-react**, and **Framer Motion** for resume parsing, skills extraction, and ATS match scoring.

## Features
- **Vite & React**: Fast lightning-fast HMR and modular component architecture.
- **Tailwind CSS Design System**: Sleek glassmorphism, responsive cards, modern fonts, custom gradients, and dark theme.
- **Lucide-React**: Clean, vector icons for UI state and ATS metrics.
- **Framer Motion**: Smooth entry transitions, gauge animations, and accordion states.
- **Drag-and-Drop Uploader**: Supports PDF, DOCX, and text paste modes.
- **Radial ATS Gauge**: SVG circular score gauge visualizer with dynamic color grading.
- **Skills Match Matrix**: Categorized badges for matched and missing skills.
- **CORS Connected**: Ready to communicate with FastAPI at `http://localhost:8000/api/v1`.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Vite Development Server
```bash
npm run dev
```

The app will run locally at **http://localhost:5173**.
